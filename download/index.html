NETWORK STATUS

The local node works today.
The contribution network comes next.

The 0.2 alpha includes the new Manifest interface and local participation preferences, but the distributed coordinator is not yet active. Enabling a contribution setting in this alpha does not upload chats, send compute jobs, or generate real network credits.

PRIVATE MODE

Do nothing and Manifest still works.

Local AI remains useful even if every network contribution setting stays off.

SELECTIVE MODE

Compute and data are separate permissions.

The product is designed so a user can eventually contribute idle hardware without sharing personal conversations.

FIRST LAUNCH

Install once.
Manifest handles the local AI.

This alpha is not yet Apple-notarized or production-signed for Windows. Your operating system may therefore show a security confirmation the first time you open it.

MACOS

If macOS says it cannot verify Manifest

Drag Manifest into Applications first. Then open System Settings → Privacy & Security and choose Open Anyway.

WINDOWS

If Windows shows SmartScreen

Choose More info, verify the app is Manifest, then choose Run anyway. Production signing will remove most of this friction later.

ALPHA SOFTWAREThe network controls are a real product preview, not a live contribution backend.

The next engineering phase is pseudonymous node registration, signed benchmark jobs, hardware-safe scheduling, contribution receipts, and real network credits — beginning with low-sensitivity performance and evaluation workloads before any learning-data contribution system.
